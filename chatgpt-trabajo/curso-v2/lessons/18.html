Adaptar el mismo contenido a públicos diferentes

Una de las tareas más valiosas de la IA es transformar una misma información para distintos lectores sin cambiar los hechos.

Objetivo: aprender a adaptar nivel técnico, extensión, tono y foco manteniendo una base factual estable.

2. VER · Una información, cuatro versiones

DIRECCIÓN

Impacto, riesgo, decisión y cifras clave.

TÉCNICO

Detalles, metodología, supuestos y limitaciones.

CLIENTE

Beneficio, implicación práctica y siguiente paso.

NUEVO EMPLEADO

Contexto, conceptos básicos y ejemplos.

3. HACER · Controlar la transformación

Transforma el contenido siguiente para [PÚBLICO].

Mantén exactamente:
- Hechos
- Cifras
- Fechas
- Compromisos

Adapta:
- Nivel técnico
- Estructura
- Extensión
- Tono
- Prioridades del lector

No añadas afirmaciones nuevas.
Si una simplificación puede cambiar el significado, indícalo.

4. EXPERIMENTAR · Consistencia entre versiones

Crea dos versiones de un mismo contenido para públicos distintos.

Después compáralas con una tercera revisión: comprueba que las cifras, hechos y compromisos sean idénticos.

Objetivo: comprobar que la adaptación cambia la comunicación, no la realidad.

⚠️ Cuanto mayor sea el riesgo de que una simplificación cambie el significado, mayor debe ser la revisión humana.
