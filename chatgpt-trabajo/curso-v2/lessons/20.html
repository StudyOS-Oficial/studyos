Trabajar con archivos: de documento a información útil

Los archivos contienen información, pero trabajar con ellos profesionalmente exige algo más que pedir un resumen. Primero hay que definir qué queremos obtener, qué fuente estamos usando y cómo vamos a comprobar el resultado.

Objetivo: aprender a diseñar un proceso fiable para utilizar documentos, presentaciones, hojas de cálculo y otros archivos como materia prima de trabajo con IA.

1. APRENDER · El archivo no es el objetivo

El objetivo profesional no es “trabajar con un PDF”. Es resolver una tarea utilizando la información que contiene.

En lugar de “resume este manual”, una petición profesional puede ser: “extrae los procedimientos que debe seguir un empleado nuevo, ordénalos por frecuencia y señala qué pasos requieren autorización”.

2. VER · Cuatro niveles de trabajo

NIVEL 1 · ENCONTRAR

Localizar nombres, fechas, cifras, obligaciones, secciones o conceptos.

NIVEL 2 · ORGANIZAR

Convertir información dispersa en tablas, listas, categorías o cronologías.

NIVEL 3 · INTERPRETAR

Identificar patrones, diferencias, riesgos o preguntas pendientes.

NIVEL 4 · ACTUAR

Convertir el análisis en una recomendación, tarea, informe o decisión.

3. HACER · Define primero el esquema de salida

Una de las mejores formas de reducir respuestas vagas es decidir cómo debe quedar la información antes de pedirla.

Voy a trabajar con este archivo para [OBJETIVO].

Necesito obtener exactamente:
1. [...]
2. [...]
3. [...]

Devuelve el resultado en este formato:
[LISTA / TABLA / JSON / RESUMEN / CHECKLIST]

Para cada dato:
- Indica si aparece explícitamente.
- Si no aparece, escribe “NO CONSTA”.
- No inventes ni completes información.

Al final indica:
- Qué información falta.
- Qué puntos debería verificar una persona.
- Qué conclusiones NO pueden extraerse con seguridad.

4. CONTROL · La fuente manda

Si una cifra, fecha o condición importa para una decisión, vuelve al archivo original. La IA puede ayudarte a encontrar la información, pero la trazabilidad sigue siendo tu responsabilidad.

⚠️ Antes de subir archivos de empresa, comprueba qué información está permitido compartir con la herramienta y qué políticas internas existen.

5. EXPERIMENTAR · Del archivo a una tabla

Elige un archivo no confidencial. Define cinco campos que te gustaría extraer y pide una tabla estructurada.

Comprueba manualmente al menos 10 datos contra el original. Anota cualquier error y modifica la instrucción para evitarlo.
