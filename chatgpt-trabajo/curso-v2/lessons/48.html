IA para recursos humanos

RR. HH. puede usar IA para estructurar información y preparar trabajo, pero las decisiones sobre personas exigen especial cautela: privacidad, sesgo, explicabilidad y responsabilidad.

1. Casos de uso razonables

Estructurar CVExtraer experiencia y requisitos de forma homogénea.
Preparar entrevistasGenerar preguntas alineadas con competencias.
DocumentarResumir información para revisión profesional.

2. Estructurar no significa decidir

Una matriz puede comparar requisitos explícitos, pero no debería convertir una inferencia del modelo en una decisión automática sobre una persona. Separa hechos extraídos, interpretaciones y decisiones.

Control: anonimiza cuando sea posible, limita los datos tratados y establece revisión humana para cualquier decisión relevante sobre una persona.

3. Métricas

Mide tiempo de cribado, consistencia de extracción, porcentaje de campos incompletos y tasa de correcciones. No uses solo «la IA acertó». También importa si el proceso es justo, auditable y adecuado al propósito.

Crea una plantilla de extracción de CV que devuelva únicamente evidencia observable: experiencia, formación, competencias y requisitos cumplidos/no demostrados. Añade una sección separada llamada «REVISIÓN HUMANA».
