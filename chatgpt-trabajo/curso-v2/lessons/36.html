De prompt a herramienta

Una herramienta de IA profesional no es un prompt bonito. Es un sistema que recibe una entrada definida, aplica unas reglas, produce una salida útil y permite a una persona revisar el resultado.

Objetivo: aprender a convertir un workflow que ya funciona en el diseño de una herramienta reutilizable.

1. APRENDER · El salto de nivel

PROBLEMA
WORKFLOW
INTERFAZ
IA
REVISIÓN
RESULTADO

El workflow define cómo se trabaja. La herramienta hace que ese workflow pueda repetirse sin reconstruir manualmente todo el proceso cada vez.

2. VER · Ejemplo profesional

Un equipo de RR. HH. podría pasar de “pegar un CV y pedir un resumen” a una herramienta con campos definidos: CV → criterios del puesto → extracción → comparación → preguntas de revisión → informe estructurado.

REGLA
No construyas una herramienta porque puedas. Construye cuando un proceso se repite, tiene entradas claras y una salida que puede evaluarse.

No añadas funciones innecesarias. Prioriza una primera versión sencilla y fiable.

4. EXPERIMENTAR

Elige uno de tus tres workflows de la Semana 5. Diseña su primera versión como herramienta sin pensar todavía en código. Dibuja únicamente input → proceso → output → revisión.
