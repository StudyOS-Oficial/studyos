Técnicas avanzadas de prompting

Cuando una tarea es compleja, pedir “una respuesta” puede ser demasiado ambiguo. Podemos estructurar el trabajo para que ChatGPT analice, compruebe y entregue un resultado más consistente.

Objetivo: aprender técnicas prácticas para tareas complejas sin convertir el prompting en una colección de trucos.
DescomponerTareas complejas
GuiarEl proceso
ControlarLa salida

1. APRENDER · Cuatro técnicas útiles

DESCOMPOSICIÓN

Divide el problema

En lugar de “analiza estos clientes y dime qué hacer”, separa extracción de datos, clasificación, análisis y recomendación.

EJEMPLOS

Enséñale el patrón

Proporciona uno o dos ejemplos de entrada → salida cuando el formato esperado sea difícil de describir.

CRITERIOS EXPLÍCITOS

Define cómo evaluar

Indica qué condiciones debe cumplir el resultado y qué debe hacer ante incertidumbre.

SALIDA ESTRUCTURADA

Fija el formato

Usa tablas, campos o secciones cuando necesites resultados comparables y reutilizables.

2. VER · Ejemplo profesional

PROBLEMA
“Analiza estos 20 candidatos y dime cuál contratar.”
MEJOR DISEÑO
“Extrae experiencia, competencias y requisitos demostrados. Compara cada candidato con estos criterios. Señala evidencia a favor y en contra. Identifica información que falta. No tomes la decisión final; prepara una matriz para revisión humana.”

El segundo enfoque separa análisis de decisión y hace visible la evidencia.

SALIDA

Si una tarea tiene varios pasos, define explícitamente cada etapa. Esto facilita detectar dónde se produce un error.

4. PLANTILLA · Prompt por etapas

Trabajaremos en 4 etapas.

ETAPA 1 — EXTRAER
Identifica únicamente los datos relevantes.

ETAPA 2 — ANALIZAR
Aplica estos criterios:
[CRITERIOS]

ETAPA 3 — COMPROBAR
Señala datos faltantes, contradicciones e inferencias.

ETAPA 4 — PRESENTAR
Entrega una tabla con:
[ESTRUCTURA]

No pases a la siguiente etapa si falta información crítica. No inventes datos.

5. EXPERIMENTAR · ¿Una instrucción o varias?

Elige una tarea compleja y prueba dos enfoques: pedir el resultado completo de una vez y dividirlo en etapas.

Compara precisión, facilidad de revisión y tiempo total.

Conclusión: no siempre gana el prompt más largo. Gana el diseño que produce un proceso controlable.

💡 Las técnicas avanzadas tienen sentido cuando resuelven un problema concreto. No añadas complejidad solo porque “suene a prompting avanzado”.
