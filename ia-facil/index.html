Preguntas frecuentes

¿Necesito saber utilizar mucho el ordenador?

No. El curso parte de cero y explica cada paso de forma sencilla.

¿Tengo que pagar ChatGPT para hacer el curso?

El curso está pensado para aprender los fundamentos y practicar sin depender de una suscripción de pago concreta. Algunas funciones de ChatGPT pueden variar según el plan que utilices.

¿Puedo hacer el curso desde el móvil?

Sí. El contenido está pensado para que puedas aprender desde el ordenador, la tableta o el móvil.

¿Y si me cuesta seguir algún paso?

El curso está diseñado para avanzar poco a poco. Las lecciones son cortas y puedes volver a verlas cuando quieras.

¿La IA siempre dice la verdad?

No. Una parte importante del curso es aprender a detectar errores y saber cuándo hay que comprobar la información.
