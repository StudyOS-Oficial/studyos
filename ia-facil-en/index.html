01 · Getting started with AI

Get a clear picture of what AI is and how ChatGPT behaves before you rely on it. You will see where it helps, where it can be wrong, and how to start a useful conversation while staying in control.

Inside this module
  • What AI is

  • adding context
  • asking for a format
  • improving a reply
  • keeping control.

Inside this module

  • choosing who the answer is for
  • adding constraints
  • splitting tasks
  • follow-up questions

  • asking clarifying questions
  • deciding when to start a new chat.

Take a prompt apart and see how each detail changes the answer. You will practise shaping the task, context and output, then improving it through examples and revision.

Inside this module

  • examples for style
  • alternatives
  • asking for a critique
  • systematic iteration.

Learn a repeatable way to improve an answer when the first draft is not quite right. You will control detail, voice and structure, and ask for a review before using the result.

Inside this module

AI can sound certain even when it is mistaken. This module shows how to notice warning signs and check important information before acting on it.

Inside this module

  • extra care with health, money and legal topics.

Build safer habits for what you share with AI and for messages that use urgency or pressure. You will leave with a simple personal rule for handling private information.

Inside this module
  • Think before pasting
  • use placeholders
  • protect passwords and codes
  • handle documents carefully
  • spot pressure tactics
  • check senders independently
  • identify sensitive information.
